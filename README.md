# The World in One Day — 26 November 2026

A broadsheet-style front page summing up Thursday 26 November 2026: Ukraine's
strike on Russia's Savasleyka airbase as the hero story, plus Trump's tariffs
on 14 trade partners, the deadly Cairo fuel-tanker fire, the recommendation to
drop Netanyahu's Case 4000 charges, and the FCC clearing SpaceX for up to one
million satellites, with an In Brief strip (Poland's border no-fly zone, the
Cartagena supermarket siege, Macy's 100th Thanksgiving parade). `main.py`
(Python 3.13, standard library only) draws the whole page from scratch —
hand-drawn bitmap font, hand-rolled PNG encoder, no network, no randomness —
and writes a deterministic 1024x1024 image to `/output/entry.png`.
